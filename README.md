# energy-game

A turn-based strategy game about national energy economies, 2025 to 2050, one turn per quarter
(100 turns). You lead one country; your score is your nation's prosperity multiplied by how the
world did on climate. No war: conflict runs through tariffs, export controls, sanctions, and deals.

This repository currently holds the **headless simulation** (Python, no UI), used to prove the
core tension and tune the numbers. See:

- `docs/DESIGN.md`: game design, the source of truth
- `docs/BUILD_SIM_V0.md`: what the simulation builds now, milestone by milestone
- `docs/ASSUMPTIONS.md`: modelling choices not in the design doc
- `data/SOURCES.md`: where every real-world starting value comes from

## Setup

```bash
python -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"
```

## Commands

```bash
pytest -q                                   # tests
ruff check . && ruff format --check .       # lint
python -m sim.runner run --country IND --bot balanced --seed 1 --out runs/ind_balanced_1 --difficulty hard
python -m sim.runner batch --config scripts/batch_default.yaml --workers 8
python -m sim.balance --workers 8           # regenerate docs/BALANCE_REPORT.md (~3 min, 6 seeds)
python -m sim.runner run --country USA --bot ai --seed 1 --out runs/ai_only  # AI-only world
python -m sim.report bau                    # business-as-usual calibration tables
python -m sim.report ai                     # the same for the AI-only world

# Play it yourself, one quarter per command (see docs/PLAYTEST.md)
python -m sim.play new --country IND --seed 1 --save games/ind1
python -m sim.play show games/ind1
python -m sim.play actions
python -m sim.play turn games/ind1 '[{"type": "set_carbon_price", "level": 20}]'
python -m sim.play wait games/ind1 4
```

Country data is generated by `scripts/data_prep/build_countries.py` from downloaded source files
(see `data/SOURCES.md`); the simulation itself never goes online.

A run writes `history.jsonl` (one line per turn), `summary.json`, and the final `state.json`.
Same seed and inputs always produce byte-identical output.

## Status

- **M0 (scaffold):** done. Config loader, seeded RNG, serializable state, CLI.
- **M1 (world model):** done. 16 nations start from 2024-2025 data; energy dispatch, fossil
  trade, GDP growth, FX, approval, climate and learning curves run for 100 quarters.
  See `docs/CALIBRATION.md`.
- **M2 (actions, bots, scoring):** done. 12 actions with slots and political capital, a
  cost-responsive market builder, four bots (`all_fossil`, `all_clean`, `balanced`,
  `deal_maker`) plus `noop`, the Nation Index, World Multiplier, bonuses and endings.
- **M3 (AI nations):** done. A deterministic utility AI with four personalities plays every
  nation without a player, following assumed target paths. `--bot ai` runs an AI-only world.
- **M4 (trade and diplomacy):** done. Clean-slate trust, goods and clean-tech trade with
  tariffs, the carbon club, equipment-on-credit and energy-as-a-service deals, a carbon credit
  market priced by supply and demand, and stocktakes against a 1.5 degC budget.
- **M4b part 1 (domestic economy and elections):** done. Taxes, tax credits, factories and
  domestic content, energy jobs and retraining, electrification programmes, and four-yearly
  economic elections (since M7, losing one ends the game).
- **M4b part 2 (climate and cooling):** done. Short-lived warming (methane, aerosols), carbon
  removal, a global forest fund, and a rest of the world that decarbonises with the 16 nations.
  An all-out world can end colder than 2025.
- **M5 (deals, difficulty, scoring, balance):** done. Equity-for-energy (with failure risk) and
  climate loans, world difficulty (easy/normal/hard) with seeded climate disasters and factory
  disruptions, absolute and relative scoring with country difficulty, a parallel batch harness,
  and `docs/BALANCE_REPORT.md` (5 of 7 criteria pass, 2 marked TUNE with reasons).
- **M6 (mechanics pass):** done. Scoring weighted toward the economy with a linear World
  Multiplier, world difficulty that changes scores (stronger disasters, damage and disruption
  multipliers), blackouts that erode stability, and bots that check what they can afford. All 7
  balance criteria pass.
- **M7 (text interface):** done. Losing an election ends the game (incumbency retuned so steady
  play usually survives), and a playable command-line game (`python -m sim.play`) with saves,
  a game screen, an action catalogue and a player guide for agent playtests. 6 of 7 balance
  criteria pass; viable strategies is marked TUNE because the scripted bots ignore elections.
- **M8 (mechanics pass after the pilot playtest):** done. Fixes the pilot's exploits and bugs
  (tax timing, always-accepted counter-offers, a season-flickering bonus, coal arriving after a
  fossil ban), caps banked slots, makes talks cheaper and storage dearer, keeps deal offers
  flowing to fast-growing clean nations, shows bonus races and policy effects on screen, and
  sets Champion at 1.6 degC and falling. Then a seven-agent playtest round
  (docs/PLAYTEST_REPORT.md).
