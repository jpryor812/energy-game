# energy-game

A turn-based strategy game about national energy economies, 2025 to 2050, one turn per quarter
(100 turns). You lead one country; your score is your nation's prosperity multiplied by how the
world did on climate. No war: conflict runs through tariffs, export controls, sanctions, and deals.

This repository currently holds the **headless simulation** (Python, no UI), used to prove the
core tension and tune the numbers. See:

- `docs/DESIGN.md`: game design, the source of truth
- `docs/BUILD_SIM_V0.md`: what the simulation builds now, milestone by milestone
- `docs/ASSUMPTIONS.md`: modelling choices not in the design doc
- `data/SOURCES.md`: where every real-world starting value comes from

## Setup

```bash
python -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"
```

## Commands

```bash
pytest -q                                   # tests
ruff check . && ruff format --check .       # lint
python -m sim.runner run --country IND --bot balanced --seed 1 --out runs/ind_balanced_1 --difficulty hard
python -m sim.runner batch --config scripts/batch_default.yaml --workers 8
python -m sim.balance --workers 8           # regenerate docs/BALANCE_REPORT.md (~3 min, 6 seeds)
python -m sim.runner run --country USA --bot ai --seed 1 --out runs/ai_only  # AI-only world
python -m sim.report bau                    # business-as-usual calibration tables
python -m sim.report ai                     # the same for the AI-only world

# Play it yourself, one quarter per command (see docs/PLAYTEST.md)
python -m sim.play new --country IND --seed 1 --save games/ind1
python -m sim.play show games/ind1
python -m sim.play actions
python -m sim.play turn games/ind1 '[{"type": "set_carbon_price", "level": 20}]'
python -m sim.play wait games/ind1 4
```

Country data is generated by `scripts/data_prep/build_countries.py` from downloaded source files
(see `data/SOURCES.md`); the simulation itself never goes online.

A run writes `history.jsonl` (one line per turn), `summary.json`, and the final `state.json`.
Same seed and inputs always produce byte-identical output.

## Play in the browser (local)

```bash
python -m web
```

Then open http://127.0.0.1:8765. The page is a map-first strategy interface: click a nation
or region for its panel and interactions, pick orders from the menu bar, and end the quarter.
It talks only to the local server (`web/server.py`), which plays through the same
`sim.session` as the text game, so saves in `games/web/` can be continued with
`python -m sim.play`. The page loads its map shapes, fonts and two small libraries from public
CDNs; the simulation stays offline.

## Agent playtests (OpenRouter)

`scripts/playtest_agent.py` has a model play a full game through `python -m sim.play` and write
the report from `docs/PLAYTEST.md`. It runs outside the simulation, which stays offline.

1. `cp .env.example .env` and fill in `OPENROUTER_API_KEY` and `OPENROUTER_MODEL` (a model that
   supports tool calling). `.env` is git-ignored.
2. Run one agent per terminal, each with its own folder under `games/`:

```bash
python scripts/playtest_agent.py --country IND --seed 23 --name r2_ind
```

```bash
python scripts/playtest_agent.py --country EUU --seed 1 --name r2_hunt --hunter
```

Each run leaves `notes.md`, `report.md` and `transcript.jsonl` in its folder. `--max-steps`
(default 400) caps the number of model requests, and so the cost.

## Status

- **M0 (scaffold):** done. Config loader, seeded RNG, serializable state, CLI.
- **M1 (world model):** done. 16 nations start from 2024-2025 data; energy dispatch, fossil
  trade, GDP growth, FX, approval, climate and learning curves run for 100 quarters.
  See `docs/CALIBRATION.md`.
- **M2 (actions, bots, scoring):** done. 12 actions with slots and political capital, a
  cost-responsive market builder, four bots (`all_fossil`, `all_clean`, `balanced`,
  `deal_maker`) plus `noop`, the Nation Index, World Multiplier, bonuses and endings.
- **M3 (AI nations):** done. A deterministic utility AI with four personalities plays every
  nation without a player, following assumed target paths. `--bot ai` runs an AI-only world.
- **M4 (trade and diplomacy):** done. Clean-slate trust, goods and clean-tech trade with
  tariffs, the carbon club, equipment-on-credit and energy-as-a-service deals, a carbon credit
  market priced by supply and demand, and stocktakes against a 1.5 degC budget.
- **M4b part 1 (domestic economy and elections):** done. Taxes, tax credits, factories and
  domestic content, energy jobs and retraining, electrification programmes, and four-yearly
  economic elections (since M7, losing one ends the game).
- **M4b part 2 (climate and cooling):** done. Short-lived warming (methane, aerosols), carbon
  removal, a global forest fund, and a rest of the world that decarbonises with the 16 nations
  (seven regions since M15). An all-out world ended colder than 2025 (just above since M15).
- **M5 (deals, difficulty, scoring, balance):** done. Equity-for-energy (with failure risk) and
  climate loans, world difficulty (easy/normal/hard) with seeded climate disasters and factory
  disruptions, absolute and relative scoring with country difficulty, a parallel batch harness,
  and `docs/BALANCE_REPORT.md` (5 of 7 criteria pass, 2 marked TUNE with reasons).
- **M6 (mechanics pass):** done. Scoring weighted toward the economy with a linear World
  Multiplier, world difficulty that changes scores (stronger disasters, damage and disruption
  multipliers), blackouts that erode stability, and bots that check what they can afford. All 7
  balance criteria pass.
- **M7 (text interface):** done. Losing an election ends the game (incumbency retuned so steady
  play usually survives), and a playable command-line game (`python -m sim.play`) with saves,
  a game screen, an action catalogue and a player guide for agent playtests. 6 of 7 balance
  criteria pass; viable strategies is marked TUNE because the scripted bots ignore elections.
- **M8 (mechanics pass after the pilot playtest):** done. Fixes the pilot's exploits and bugs
  (tax timing, always-accepted counter-offers, a season-flickering bonus, coal arriving after a
  fossil ban), caps banked slots, makes talks cheaper and storage dearer, keeps deal offers
  flowing to fast-growing clean nations, shows bonus races and policy effects on screen, and
  sets Champion at 1.6 degC and falling. Then a seven-agent playtest round
  (docs/PLAYTEST_REPORT.md).
- **M9 (mechanics pass after playtest round 1):** done. Climate loans build real plants,
  factories age out and score on sales, the vote averages prices and jobs over the term,
  hosted deal capacity is capped, club members below the minimum price leave, rank follows the
  final score, 3 domestic and 2 diplomatic slots a quarter, a market reserve against
  peak-quarter blackouts, and screen fixes. The second agent playtest round is not run yet.
- **M10 (permitting reform):** done. `set_permitting` speeds up builds (grid and wind most)
  at a cost in approval and a local-opposition term in the vote that varies by country, and
  `scripts/playtest_agent.py` runs a playtest agent through OpenRouter (key in `.env`).
- **M11 (more energy sources):** done. Wind is split into onshore and offshore wind and other
  renewables into bioenergy and geothermal (13 sources in all). The country split shares are
  approximate and marked as placeholders until checked against Ember or IRENA.
- **M12 (tech tree):** done. Twelve technologies (`fund_research`): upgrades to existing
  sources, carbon-capture retrofits, and new sources from small modular reactors to fusion.
  Research is time-based and faster with more funding; AI nations race too.
- **M13 (licensing):** done. Sell licences to technologies you researched (`set_license_price`,
  with export controls) and buy them from others (`buy_license`); AI nations price by rule;
  patents expire after ten years.
- **M14 (fixes from playtest round 2):** permitting reform costs half the votes, its backlash
  fades after a term and faster builds are cheaper; the election line shows the swing range,
  the growth gap and the levers; score changes are reported each quarter; tax cuts to -2
  points; a "Staying in office" section in the playtest guide.
- **M15 (rest of the world and minor-nation events):** the rest of the world is seven regions
  built from 2024 data, whose new energy gets cleaner as clean tech gets cheaper and the big
  economies cut; nations lend for clean energy there (`finance_region`, limited by what each
  region can absorb), and seeded events (an oil discovery, a rainforest, a coal plan, an
  adaptation appeal) ask the world to fill a shared fund (`pledge_to_event`).
- **W1 (local web interface):** `python -m web` serves a playable map-first interface: a
  painted political map with map modes, a resource bar with breakdowns, alerts, nation and
  region panels with interactions, order menus with live checks, quarterly dispatches, and
  event and election windows.
- **W2 (web interface, deeper screens):** a Chronicle of the game so far (warming, world and
  your CO2, GDP, approval, capital as synced small multiples with a table view), a research
  tree with prerequisite arrows and fund or licence buttons, deal screens that explain each
  deal type and show an offer's terms from your side, build costs per source, and planned
  orders kept across page reloads.
- **Nation selection screen:** a Civ-style chooser with an abstract leader portrait, the six
  nations listed easiest first, and each nation's strengths, weaknesses and 2025 figures,
  derived from the starting data.
- **Left-hand order rail:** the order menus and map modes stack down the left edge; a menu
  opens a tall drawer of its orders, each unfolding in place into its form.
- **M16 (fixes from playtest round 3):** tax cuts are mostly borrowed instead of emptying the
  energy budget, the screen shows where capital comes from, amounts a hair over a limit are
  trimmed rather than refused, forest payments wear off and earn less credit, and the playtest
  runner waits out OpenRouter's in-flight limit.
